# Sorpresa de cumpleaños

## Personalizar

1. La foto adjunta ya está guardada como `mi-foto.jpg` en esta carpeta. Puedes reemplazarla por otra foto con el mismo nombre, o cambiar el `src` de `#memoryPhoto` en `index.html`.
2. Opcionalmente, copia `viento.mp3`, `hover.mp3` y `carta.mp3` a esta carpeta. También puedes editar las rutas de los elementos `<audio>` en `index.html`. Si no están disponibles, el navegador genera efectos de sonido sencillos con Web Audio.
3. Escribe tu felicitación dentro de `<div class="letter-message">` en `index.html`. La zona de la carta también se puede editar al abrirla en el navegador, pero para conservar ese texto en el sitio, edita y publica el HTML.
4. Para cambiar la cantidad de velas, modifica `candleCount` en `script.js`.

## Publicar en GitHub Pages

Sube el contenido de esta carpeta a la raíz del repositorio o a una carpeta `docs`. En GitHub, abre **Settings → Pages**, elige **Deploy from a branch**, selecciona la rama y la carpeta raíz o `docs`, y guarda.

La foto y los MP3 deben subirse al repositorio con las rutas que indiques en el HTML. Los navegadores suelen requerir que la persona toque la página para permitir audio; por eso los efectos comienzan con las interacciones.
